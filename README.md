# 招聘岗位数据采集与大模型对比实验项目

本项目是一个围绕招聘岗位数据展开的数据采集、存储、分析与实验对比项目。项目包含多个招聘平台的爬虫代码、主程序入口、大模型与其他基线算法的对比实验代码，以及用于测试和演示的示例数据库。

项目主要目录包括 `src` 和 `data` 两个文件夹。其中，`src` 文件夹存放项目源代码，`data` 文件夹存放示例数据库。

---

## 一、项目简介

本项目主要用于招聘岗位数据的获取与分析，并结合大模型方法和传统基线算法进行对比实验。

项目支持从以下招聘平台采集岗位数据：

- 猎聘网
- 智联网
- BOSS 直聘

项目还提供了主程序和测试程序，方便用户基于示例数据库运行项目，并对大模型方法与其他基线算法进行实验比较。

---

## 二、项目功能

本项目主要包含以下功能：

1. 招聘岗位数据爬取  
   通过不同爬虫脚本从招聘网站采集岗位相关信息。

2. 示例数据库读取  
   `data` 文件夹中提供了示例数据库，可用于快速运行和测试项目。

3. 主程序运行  
   通过 `app.py` 运行项目的主要功能。

4. 大模型调用  
   项目中涉及大模型 API 调用，用于完成相关分析或实验任务。

5. 对比实验  
   通过 `test.py` 对大模型方法和其他基线算法进行比较实验。

## 四、文件说明

### 1. `src/app.py`

`app.py` 是本项目的主要程序文件，用于运行项目的核心功能。

该文件可能会读取 `data` 文件夹中的示例数据库，并结合大模型 API 或其他算法完成相应的数据处理、分析或预测任务。

需要注意的是，`app.py` 中原本涉及的大模型 `API_KEY` 已经删除。用户在运行该程序前，需要在代码中自行填写可用的 API Key。

---

### 2. `src/test.py`

`test.py` 是项目中的实验测试文件，主要用于进行大模型与其他基线算法的对比实验。

该文件可用于测试不同方法在相同数据集或任务上的表现，从而评估大模型方法相较于传统算法或其他基线方法的效果。

同样需要注意，`test.py` 中原本涉及的大模型 `API_KEY` 已经删除。用户在运行该文件前，需要在代码中自行填写自己的 API Key。

---

### 3. `src/sele.py`

`sele.py` 是猎聘网爬虫文件。

该文件用于从猎聘网采集招聘岗位相关数据，例如岗位名称、公司名称、薪资、地点、经验要求、学历要求、岗位描述等信息。

由于招聘网站页面结构可能发生变化，如果爬虫运行异常，需要根据网站最新页面结构对代码进行调整。

---

### 4. `src/zhilian.py`

`zhilian.py` 是智联网爬虫文件。

该文件用于从智联网采集招聘岗位数据，并可将采集到的数据用于后续分析、存储或实验。

运行该爬虫时，需要保证网络环境正常，并注意控制爬取频率。

---

### 5. `src/boss.py`

`boss.py` 是 BOSS 直聘爬虫文件。

该文件用于从 BOSS 直聘采集招聘岗位数据。

由于 BOSS 直聘等招聘网站可能存在反爬机制，运行该文件时可能需要根据实际情况调整请求方式、页面解析逻辑或浏览器自动化配置。

---

### 6. `data`

`data` 文件夹中存放的是示例数据库。

该数据库可用于项目演示、程序测试和实验验证。用户可以直接使用该示例数据库运行 `app.py` 或 `test.py`，也可以使用爬虫重新采集数据后替换或扩展数据库。

`test.py` 主要用于大模型与其他基线算法的对比实验。

1. 使用示例数据库作为实验数据；
2. 调用大模型 API 进行任务处理；
3. 使用其他基线算法进行同一任务处理；

实验结果可能受到以下因素影响：

- 数据库规模；
- 数据质量；
- 数据清洗方式；

- API 调用参数；
- 基线算法参数；

- 网络稳定性；
- 运行环境差异。

为了获得更稳定的实验结果，建议在相同数据集、相同参数设置和相同运行环境下多次运行实验。

## 十二、常见问题

### 1. 运行时报 API Key 错误怎么办？

请检查 `src/app.py` 或 `src/test.py` 中是否已经填写了有效的 API Key，并确认该 Key 具有调用对应大模型接口的权限。

如果 API Key 已经过期、被禁用或额度不足，也可能导致调用失败。

---

### 2. 数据库文件找不到怎么办？

请确认 `data` 文件夹是否存在，并检查代码中读取数据库的路径是否与实际文件路径一致。

建议在项目根目录下运行程序，例如：

```bash
python src/app.py
```

或：

```bash
python src/test.py
```

如果仍然报错，可以尝试把app.py或test.py放到根目录下运行。

---

### 3. 爬虫无法正常运行怎么办？

爬虫无法运行可能由以下原因导致：

- 目标网站页面结构发生变化；
- 网络连接异常；
- 网站存在反爬机制；
- 请求频率过高；
- 请求头、Cookie 或登录状态失效；
- Selenium 或浏览器驱动配置不正确；
- 页面元素选择器失效。

可以根据报错信息检查代码中的请求逻辑、页面解析逻辑、浏览器驱动配置和网络环境。

---

### 4. 实验结果与预期不一致怎么办？

实验结果可能受到数据、模型、算法和运行环境等多方面因素影响。

建议检查以下内容：

- 数据库内容是否正确；
- 数据预处理方式是否一致；
- 大模型 API 是否可用；
- 基线算法参数是否设置合理；
- 是否存在随机性影响；
- 是否需要固定随机种子；
- 是否在相同数据集上进行比较。

---

### 5. 依赖安装失败怎么办？

如果依赖安装失败，可以尝试以下方法：

```bash
python -m pip install --upgrade pip
```

然后重新安装依赖。

如果某些库安装速度较慢，可以使用国内镜像源，例如：

```bash
pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple
```
